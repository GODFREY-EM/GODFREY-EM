## 🔒 Security First

Securing what I build and deploy isn't a chore — it's the fun part. My toolkit is straight out of Kali: Burp Suite, OWASP ZAP, Nuclei, Wafw00f, Postman for API testing. Break into your own systems before someone else does and you've already won. Current on PHP package vulnerabilities via [`security-advisories`](https://github.com/GODFREY-EM/security-advisories).
